# 🛡️ AI Risk Manager

AI Risk Manager is a Flask-based web application that analyzes financial transactions and assigns a risk score and risk level.

## 🚀 Features

- Enter transaction details
- AI-based transaction risk analysis
- Risk score generation
- Risk classification
  - 🟢 Low Risk
  - 🟡 Medium Risk
  - 🔴 High Risk
- Recommended action based on risk
- Store transactions in SQLite database
- View previous transactions
- Dashboard with transaction statistics

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2

## 🔄 Project Workflow

User enters transaction details  
↓  
Risk Analysis  
↓  
Risk Score  
↓  
Risk Level  
↓  
Recommended Action  
↓  
Transaction stored in database  
↓  
Dashboard

## 📊 Dashboard

The dashboard displays:

- Total transactions
- High-risk transactions
- Medium-risk transactions
- Low-risk transactions
- Recent transactions
